# GitHub 发布验证

日期：2026-11-08。版本：2.2.0。目标：Windows 10/11 x64。

本记录描述本次重新构建和公开发布准备。旧的开发日志与截图没有复制到公开源码。

- 使用 .NET SDK 9.0.308 从当前源码重新生成 Release 自包含 Windows x64 应用，关闭调试符号并映射编译路径。
- 从公开源码白名单复制出的独立目录再次还原、构建与自包含发布成功；Zhidian.exe、Zhidian.dll 和 Qiban.Core.dll 与正式发布暂存文件的 SHA-256 完全一致。
- 210 项核心断言、69 项网络/进程检查及 238 项真实 WPF 回归全部通过；使用隔离数据及模拟服务，不调用用户实际聊天服务。
- Python worker、资源准备、裁剪及诊断测试 29 项通过；14 项发布审计测试通过。引擎的 15,261 个文件（不计清单自身）、9,580,883,634 字节逐个与既有封装清单核验大小和 SHA-256 通过。
- 发布目录和 ZIP 执行白名单、公共资源来源、常见凭据、本机路径、用户数据及运行残留检查；ZIP 全部成员与原文件 SHA-256 对照。
- 源码按明确目录与文件类型复制，排除 bin/obj、构建缓存、历史归档、输出物、用户数据和旧测试日志；逐个记录 SHA-256。
- 完整 ZIP 切分为每卷不超过 1,900,000,000 字节的连续切片，每卷写入后重新读取验证。分卷提取器的 14 项 Windows PowerShell 5.1 测试全部通过，包含成功、长路径、缺卷、损坏、已有目标及路径边界测试。

本轮不重新使用用户的私人声模做真实语音合成；此前真实引擎验证的型号、语言、设备及限制见 `voice-inference-validation.json` 与 `VOICE_ENGINE.md`。本机测试不能替代所有 Windows 硬件和第三方模型组合验证。

最终附件清单以 `release-manifest.json`、`SHA256SUMS.txt` 为准。首次解压启动检查在单独副本中执行，测试生成的 data/cache 不会进入分发包。
