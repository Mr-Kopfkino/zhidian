# 界面主题

在“设置 → 外观 → 界面风格”选择标准或 Windows XP。选择后立即生效并保存；主题只影响应用自身。

Windows XP 风格以经典蓝色窗口为参考：高饱和蓝色标题栏、蓝色面板、白色标签、浅色输入框、立体按钮及琥珀色焦点描边。聊天气泡保留清晰的文字对比度。主题通过 WPF 矢量资源绘制，无需下载桌面美化工具、浏览器组件或背景图片。

素材与样式参考：

- [XP.css](https://github.com/botoxparty/XP.css)：采用 MIT 许可。标题栏渐变按其 `themes/XP/_window.scss` 适配为 WPF；保留许可于 `licenses/XP.css-LICENSE.txt`。参考版本为 2026-11-08 检索的 main。
- [XP.css 控件预览](https://botoxparty.github.io/XP.css/)：窗口、按钮、输入和下拉菜单的视觉参考。
- [Microsoft WPF Luna](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/Themes/PresentationFramework.Luna/Themes/Luna.NormalColor.xaml)：原生控件样式参考。

未分发 Windows 安装文件、微软商标或桌面壁纸。运行平台为 Windows 10/11，Windows XP 仅表示界面风格。
