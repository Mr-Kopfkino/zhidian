# 致电 v2.2.0

可以由你定义的 Windows 桌面电子朋友，支持角色设定、流式聊天、长期记忆、主动聊天、角色语音与日语聊天模式。

## 下载并运行

支持 **Windows 10 / 11，x64**。下载本 Release 的全部 9 个附件，放在同一目录并保留原名：四个 `Zhidian-v2.2.0-win-x64.zip.001` ～ `.004` 分卷、`Extract-Zhidian.cmd`、`Extract-Zhidian.ps1`、`release-manifest.json`、`README-DOWNLOAD.txt`、`SHA256SUMS.txt`。

预留至少 **22 GB** 可用空间，双击 **Extract-Zhidian.cmd**。脚本校验每卷和完整 ZIP 后解压；完成后进入 `Zhidian-v2.2.0-win-x64` 文件夹，双击 **Zhidian.exe**。

完整便携包自带 .NET、Python、语音推理环境与公共基础资源，不需要安装开发工具或 CUDA Toolkit。附件总计约 7.34 GB，解压后约 9.72 GB。分卷必须全部下载，不能单独解压；GitHub 自动提供的 Source code 是开发源码，不是运行包。

## 首次设置

- 在「设置 → 对话模型」填写兼容 Chat Completions 的服务地址、模型 ID 和自己的可选密钥。支持本地或远程服务；本包不附带聊天大模型或付费账户。
- 内置语音需要自行选择有权使用的 GPT / SoVITS 角色权重与参考音频，并填写参考文本。包内不附带私人声模或参考录音。
- 程序目录需要写入权限；请完整解压，不要直接从 ZIP 内启动。API 密钥使用当前 Windows 账户加密。

## 本版功能

- 默认开启自动整理长期记忆和对话摘要，可分别关闭。整理由已配置的模型完成；每条候选校验原文依据，保留来源，并区分自动生效与待确认。
- 普通聊天优先于后台整理；失败后重试，切换角色、删除或归档来源时丢弃过期结果。
- 保留标准与 Windows XP 两种外观、多角色独立配置、主动聊天、自定义背景、GPT-SoVITS 内置/外接语音及日语原文朗读。

主动聊天、日语翻译与自动记忆整理可能额外调用用户配置的模型服务，费用按该服务规则计算。

## 旧版升级

关闭新旧程序，先备份旧目录。使用包内 `Upgrade-Data.ps1` 将旧程序的完整 `data` 复制到尚无 `data` 的新目录，完成后再启动新版。不要合并两个已有的 data 目录；换电脑或 Windows 账户后重新填写密钥。

## 发布检查与许可

源码和附件排除用户聊天、个人配置、密钥、私人声模及运行缓存。分卷附 SHA-256 校验，解压器会自动核对。应用和引擎的验证范围见源码 `docs/PUBLICATION_VALIDATION.md`。

项目原创源码采用 MIT；第三方运行库、语音组件、模型资源和角色资料按各自许可使用，详见包内 `THIRD_PARTY_NOTICES.md` 和 `licenses`。本版未进行应用代码签名。
